# App content draft

## Ads

Answer: `No`.

ovayuvam contains no ads and no ad SDK.

## App access

Answer: `All functionality is available without special access`.

There is no login, account, invitation code or restricted area.

## Target audience

Recommended answer: `13+` or adult/general audience, not directed to children.

Rationale: ovayuvam stores location history locally. The privacy policy says the app is not made for children and should not be used to track children or other people.

## Content rating notes

Expected questionnaire answers:

- Violence: `No`

- Controlled substances: `No`

- User-generated content: `No`

The app uses location for a private personal map. It does not show other users or publish user content.

## Account deletion

Answer: `No account creation`.

ovayuvam has no account system. Local data can be removed by uninstalling the app or clearing app data in Android settings.

If the user creates an encrypted export file, that file is outside app storage and
must be deleted by the user wherever they saved it.
