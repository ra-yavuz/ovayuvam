# Screenshot checklist

Google Play needs phone screenshots for the store listing.

Capture from a real or emulator install of `ovayuvam 0.5.10`.

Recommended screenshots:

1. First launch permission context or Android location prompt.
2. Full-screen real map with fog overlay.
3. Map after a short walk or simulated location movement, showing strong fog and a strict revealed walking trail.
4. A private goal pin on the map.
5. Off-screen goal arrow.
6. Info sheet showing privacy policy URL and encrypted export/import controls.
7. Foreground notification with progress-aware text, if available during capture.

Rules:

- Use PNG or JPEG.
- Do not show private real location if the screenshot will be public.
- Avoid misleading mock data unless it is clearly representative and not a real user route.
