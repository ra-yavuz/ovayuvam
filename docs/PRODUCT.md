# Product

## Name

Working app name: `ovayuvam`.

Public page path: `https://ovayuva.tr/yuvam/`.

The name reads as a compact "my ovayuva" idea and keeps the parent brand visible.
The word is also close to generic Turkish "my home" language, so brand protection
should not rely on the generic part alone.

This note is not legal clearance.

## Version 1

Version 1 is a private fog-of-war map:

- Start a visible tracking session.
- Walk, travel, or explore.
- Open the app to see visited areas revealed.
- Keep the data on the device.
- Export, import, or delete your local world manually.
- Do not create an account.
- Do not publish anything.

## Later

Later versions can add:

- Encrypted Google Drive backup.
- Encrypted restore on a new phone.
- Friend groups.
- Shared group worlds.
- Selective sharing by area or trip.
- Optional offline basemap packs.

The default mode should remain private.
